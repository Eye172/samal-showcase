## The challenge

Build an agentic workflow that forecasts **hourly wind-power output 24–48 hours ahead** for two turbines. The agent retrieves archived weather forecasts for the turbine locations, prepares the inputs, runs the forecasting model, analyses the result and updates the forecast as new inputs become available.

The task specifies historical turbine data from **March 2023 through 31 January 2026**, followed by a **1–28 February 2026** test period. Daily historical replay begins on 31 January and advances through February. Each issue must use the weather forecast available at that issue time.

The participant files contain record IDs, timestamps, mean wind speed (m/s), normalized active power and mean ambient temperature (°C). Full turbine CSV files are not included in this showcase.
